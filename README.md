# 🛍️ Luxe Store - Mini E-commerce Website

## Overview

Luxe Store is a modern mini e-commerce web application built using PHP, MySQL, Bootstrap 5, HTML, CSS, and JavaScript. The project provides a responsive and user-friendly shopping experience with dynamic product listings and shopping cart functionality.

## Features

* Dynamic product catalog
* Add products to cart
* Update cart quantities
* Remove products from cart
* Session-based cart management
* Responsive Bootstrap design
* Modern and attractive user interface
* MySQL database integration

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/luxe-store.git
```

2. Move the project folder to:

```text
C:\xampp\htdocs\
```

3. Create a MySQL database named:

```sql
mini_ecommerce
```

4. Import the `mini_ecommerce.sql` file.

5. Update database credentials in `config.php` if needed.

6. Start Apache and MySQL from XAMPP.

7. Open:

```text
http://localhost/luxe-store
```
